# PAIR Lab — Coming soon

A temporary landing page for the Providence Artificial Intelligence and Robotics Lab at Providence College.

## Publish with GitHub Pages

1. Extract this ZIP file.
2. Upload the **contents** of the `pair-lab-landing` folder to the root of the lab repository. The repository root should contain `index.html`, `.nojekyll`, and the `assets` folder. Do not upload only the ZIP or leave everything inside an extra folder.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose **main** (or the branch you uploaded to), select **/ (root)**, and click **Save**.
6. Wait for the Pages deployment to finish. GitHub will show the published URL in **Settings → Pages**.

If Pages is already configured for the repository, use its existing publishing branch and folder. This page does not require a build step or GitHub Actions workflow.

## Edit or preview

- Open `index.html` in a browser to preview the page locally.
- Edit the text and the CSS inside `index.html` to make changes.
- Only the supplied black-and-white logo is included in `assets/`. CSS inverts it to display white lettering on the black background; the source image remains unchanged.
- All content is centered horizontally and vertically, with white text on a black background.
- Relative asset paths support both organization Pages sites and project repository Pages sites.
- The page uses system fonts and contains no external scripts, analytics, or dependencies.

When the complete website is ready, replace this landing page with the finished site.
